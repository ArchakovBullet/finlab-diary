### 💡 Задачи по парной торговле

1. **Динамическая оптимизация параметров:**
   - Для каждой пары подбирать: окно (10-60), порог входа (1.5-3.0), порог выхода (0-1.0)
   - Критерий: Sharpe ratio или win-rate × avg_pnl
   - Обновлять раз в неделю/месяц

2. **Авто-тест стационарности:**
   - Тест Дики-Фуллера (ADF) каждую неделю
   - Отключать пары с p-value > 0.05
   - Включать новые пары при восстановлении стационарности

3. **Фильтр по тренду:**
   - Не входить против сильного тренда спреда
   - Использовать ADX спреда > 25 как запрет на вход

4. **Интеграция в дашборд:**
   - Показывать активные/неактивные пары
   - Сигналы в реальном времени по Z-score
   - График спреда с уровнями входа/выхода
