# Дневник разработки FinLabPy — 25.05.2026

## Тема: Продолжение отладки сборщиков — проблема выходных дней

### Проблема
Health-check показал ❌ для Super Candles и Super Candles H4. Они не обновлялись с 23 мая (суббота). Остальные сборщики (HI2, Funding, TradeStats) работали нормально.

### Диагностика
1. **Super Candles collector** — cron-задача была с ограничением `1-5` (будни), но мы вчера исправили на `* * *` (ежедневно)
2. **FutOI и Candles collector** — всё ещё имели ограничение `1-5`, поэтому не работали в выходные
3. **H4 агрегатор** — пытался собрать данные за 23-24 мая (выходные), но исходных Super Candles за эти дни не было
4. **Health-check** — ругался на отсутствие обновлений, хотя для выходных это нормально

### Решение

#### 1. Унификация расписания сборщиков
Все три часовых сборщика переведены на ежедневный режим (без ограничения по дням недели)

#### 2. Ручной запуск недостающих сборщиков
- Super Candles: запущен вручную, собрано 7229 записей за 25.05
- Super Candles дневная агрегация: создан файл за 24.05 (153 строки, 9 тикеров)

#### 3. Исправление Git-remote для data-репозиториев
Обновлены remote URL для всех 7 репозиториев данных — теперь используют переменную `${GITHUB_TOKEN}`

### Инцидент с токеном
- В репозитории `finlab-infrastructure` обнаружен GitHub-токен в открытом виде
- Токен отозван через GitHub Settings
- Создан новый токен, сохранён в `~/.bashrc` как переменная `GITHUB_TOKEN`
- Все скрипты пуша обновлены: вместо хардкода → `${GITHUB_TOKEN}`
- Репозиторий переписан через `git filter-branch` для удаления токена из истории

### Результат
- ✅ Все сборщики переведены на ежедневный режим (без выходных)
- ✅ Токены больше не хранятся в репозиториях
- ✅ Инфраструктурный репозиторий обновлён и безопасен
